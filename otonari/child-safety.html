児童の安全に関する基準

制定日: 2026年10月9日

オトナリ - 音隣(以下「本アプリ」)は、ライブの同行者をさがすためのアプリです。本アプリは児童の性的搾取および虐待(CSAE: Child Sexual Abuse and Exploitation)を一切許容しません。本ページは、その防止のために定めている基準と、問題を見つけたときの通報方法を示すものです。

1. 禁止する行為

本アプリでは、以下の行為を禁止します。発見した場合は、通報の有無にかかわらず対応します。

  • 児童性的虐待コンテンツ(CSAM)の送信・投稿・共有・要求
  • 児童を性的に描写する、または性的対象として扱う内容の送信・投稿
  • 児童に対する性的な目的での接触、信頼関係の構築(グルーミング)
  • 児童との性的な接触を求める、またはそれを示唆する内容の送信
  • 児童の性的な画像・動画の売買、取引の持ちかけ
  • 年齢を偽って利用すること、および他の利用者に年齢を偽らせること

2. 本アプリの設計上の対策

  • 交際を目的とする利用の禁止: 本アプリはライブの同行者をさがす目的に限って利用できます。異性を指定して相手をさがす機能は設けていません。交際を目的とする利用は利用規約で禁止しています。
  • やりとりの開始に相手の同意が必要: 一方的にメッセージを送ることはできません。募集への応募が承認された場合、または同行のお誘いが承諾された場合にのみ、やりとりが始まります。
  • 電話番号の確認: 募集・応募・お誘いの送信には電話番号の確認を必須としています。複数のアカウントを作ることを抑止する仕組みです。
  • 写真の自動検査: 送信された写真は、相手に届く前に Cloud Vision API (SafeSearch) で自動検査します。不適切と判定された写真は相手に届かず削除され、運営の確認対象として記録されます。
  • 文面の自動検知: 募集の説明文、自己紹介、お誘いの本文、メッセージについて、交際を目的とする文言などを自動で検知し、運営の確認対象として記録します。
  • メッセージの保全: 送信されたメッセージと写真は、送信者が取り消すことはできません。通報があったときに運営が内容を確認できる状態を保つためです。

3. 通報の方法

アプリ内から通報できます。募集の詳細画面、プロフィール画面、やりとりの画面にある通報ボタンから、理由として「児童の安全に関わる内容があった」を選んでください。

アプリを使えない状況の場合、または緊急の場合は、下記の連絡先まで直接ご連絡ください。

4. 通報を受けたときの対応

  1. 通報を受領した時点で、対象の内容を他の利用者から見えない状態にします。
  2. 内容を確認します。確認は通報への対応のために行い、それ以外の目的では行いません。
  3. 本基準に反すると判断した場合、該当する内容を削除し、アカウントを停止します。再登録も認めません。
  4. 児童性的虐待コンテンツ(CSAM)に該当すると判断した場合、または児童に対する犯罪のおそれがあると判断した場合は、関係法令に従い、警察その他の関係機関へ速やかに通報します。あわせて、法令上必要な期間、確認に用いた記録を保全します。

個人開発のため24時間体制の監視は行っていませんが、児童の安全に関わる通報は他のすべての通報より優先して対応します。

5. 遵守する法令

  • 児童買春、児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律
  • インターネット異性紹介事業を利用して児童を誘引する行為の規制等に関する法律
  • 児童福祉法
  • 青少年が安全に安心してインターネットを利用できる環境の整備等に関する法律
  • 各都道府県の青少年保護育成条例
