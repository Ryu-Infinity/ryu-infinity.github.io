オトナリ - 音隣 プライバシーポリシー

制定日: 2026年10月9日

オトナリ - 音隣(以下「本アプリ」)は、利用者のプライバシーを尊重し、個人情報の保護に努めます。本ポリシーは、本アプリが収集する情報とその取り扱いについて説明するものです。

1. 収集する情報

  • 電話番号: 本人確認のため。Firebase Authentication が保持し、本アプリのデータベースには保存しません。他の利用者に表示されることもありません。
  • 表示名: 他の利用者に表示される名前。本名である必要はありません。
  • 年代・居住都道府県(任意): 同行者を選ぶ際の参考情報。生年月日は収集しません。
  • 性別(任意): 「同性を希望」という条件を使う場合のみ。初期値は「回答しない」で、入力は任意です。
  • 匿名認証ID: アカウント作成前から閲覧できるようにするための匿名識別子(Firebase Authentication)。
  • 自己紹介(任意): 好きなアーティストや参戦スタイル(200文字まで)。他の利用者に表示されます。
  • 投稿内容: 募集の内容(枚数・座席区分・座席の自由記述・金額・条件・説明文)、応募時のメッセージ、同行のお誘いの本文、やりとりのメッセージ、評価。
  • メッセージに添付した写真: お誘いが承諾された相手とのやりとりで送った写真。詳しくは「8. 写真の取り扱い」をご覧ください。
  • フォロー関係: フォローした利用者、フォローされた利用者。フォロー数は他の利用者に表示されます。
  • 登録した公演情報: アーティスト・会場・日時・ツアー名。
  • 取引の記録: 成立件数、評価、ドタキャンの記録。
  • 端末のプッシュ通知トークン(通知を許可した場合): 通知の配信のため。本人以外は参照できない領域に保存します。

本アプリは、本名・生年月日・住所・クレジットカード情報・位置情報を収集しません。

2. 収集しない情報

本アプリはチケットの代金を預かりません。したがって、クレジットカード番号・銀行口座等の決済情報を取得することはありません。

チケットの画像やQRコードをアプリに保存する機能はありません。

3. 利用目的

  • 同行者のマッチング機能の提供
  • 複数アカウントの作成防止(電話番号の確認)
  • 利用者同士が相手を選ぶための信頼情報の表示(評価・取引実績)
  • 通知の配信
  • 不適切な投稿の検知と、通報への対応
  • サービスの改善

4. 他の利用者に表示される情報

以下の情報は、他の利用者が閲覧できます。

  • 表示名、年代・居住都道府県(入力した場合)
  • 自己紹介(入力した場合)
  • 電話番号の確認済みバッジ(電話番号そのものは表示されません)
  • 取引の記録(成立件数・評価・ドタキャン率)
  • フォロー数・フォロワー数、およびその一覧
  • 募集の内容(座席の自由記述を含む)

座席の詳細を知られたくない場合は、座席の自由記述欄を空のままにしてください。

ブロックした相手の情報は、ブロックしたことが相手に伝わらない形で保存されます。

5. 第三者への提供

以下の場合を除き、取得した情報を第三者に提供することはありません。

  • 利用者の同意がある場合
  • 法令に基づく場合、または警察等の公的機関から法令に基づく要請があった場合
  • 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが困難な場合

本アプリは、情報の保管と処理に Google LLC が提供する Firebase(Authentication / Cloud Firestore / Cloud Functions / Cloud Messaging / Cloud Storage)を利用しています。データは日本国内のリージョン(asia-northeast1)に保存されます。

メッセージに添付された写真は、相手に届く前に Google LLC の Cloud Vision API による自動検査を行います。この検査のため写真は同社に送信されます。詳しくは「8. 写真の取り扱い」をご覧ください。

アーティスト情報の取得に MusicBrainz(MetaBrainz Foundation)の公開データを利用していますが、利用者の情報を送信することはありません。

6. メッセージの取り扱い

利用者同士のメッセージは送信後に編集・削除できません。これは通報があった際に運営が内容を確認できるようにするためです。

運営がメッセージの内容を確認するのは、通報への対応および法令に基づく要請があった場合に限ります。また、券面額を超える金銭の授受や詐欺を示唆する文言、交際を目的とする文言を自動で検知し、運営の確認対象として記録することがあります。この自動検知は、募集の説明文・自己紹介・同行のお誘いの本文・メッセージを対象とします。

写真については、送信前に自動検査を行います(「8. 写真の取り扱い」)。

7. データの削除

アプリ内の「設定 → 退会する」から、いつでもアカウントを削除できます。削除すると以下が行われます。

  • プロフィール情報を削除します。
  • 公開中の募集を取り下げます。
  • 認証情報(電話番号の紐付けを含む)を削除します。

なお、成立済みのやりとりの記録は相手側に残ります。相手にとっての取引記録を一方的に消すことができないためです。

削除に関するお問い合わせは下記までご連絡ください。

8. 写真の取り扱い

同行のお誘いが承諾された相手とのやりとりでは、写真を送ることができます。写真については次のとおり取り扱います。

  • 送信前の自動検査: 送信された写真は、相手に届く前に Google LLC の Cloud Vision API (SafeSearch) による自動検査を行います。検査のため、写真は同社に送信されます。成人向けの内容など不適切と判定された写真は相手に届かず削除され、運営の確認対象として記録されます。
  • 保存場所: 検査を通過した写真は Google LLC の Cloud Storage for Firebase (東京リージョン) に保存します。
  • 閲覧できる人: そのやりとりの当事者のみです。写真の所在を示す URL は、当事者だけが読めるメッセージの中にのみ記録されます。
  • 取り消しできません: 一度送信した写真は、送信者が取り消すことはできません。これは通報があったときに運営が内容を確認できる状態を保つためです。送信前に画面で明示します。
  • 退会したとき: 退会すると、ご自身が送った写真は削除されます。
  • 法令違反の疑いがある場合: 児童の性的搾取・虐待に関わる内容が確認された場合は、削除のうえ、関係法令に従い必要な対応を行います。詳しくは児童の安全に関する基準をご覧ください。

プロフィールに写真を設定する機能は現在ありません。

9. 18歳未満の方の利用

18歳未満の方は、保護者の同意を得たうえでご利用ください。

本アプリは児童の性的搾取・虐待(CSAE)を一切許容しません。対応方針と通報の方法は児童の安全に関する基準に定めています。

10. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。重要な変更を行う場合は、アプリ内で通知します。
